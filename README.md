# EliteDigital – recriação do website

Site estático (HTML + CSS + JS), sem build e sem dependências. Dados de produtos em `data/products.js`.

## Executar localmente
Basta abrir `index.html` no navegador (duplo clique). Opcionalmente, com servidor:
```bash
python3 -m http.server 8000   # http://localhost:8000
```

## Notas
- Só a página inicial está recriada; links de serviços/login apontam para elitedigital.pt.
- O catálogo tem 12 produtos reais; o checkout é apenas demonstrativo.
